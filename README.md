# Ainuo Excel SCPI Sender

## 项目简介

Ainuo Excel SCPI Sender 是一个基于 Qt 框架开发的图形界面工具，用于通过 TCP 网络向电源设备（或任何支持 SCPI 命令的仪器）批量发送 SCPI 命令。  
它可以从 Microsoft Excel 文件中读取命令列表（第一列为需发送的命令，第二列为期望的返回值），支持循环发送、可配置的命令间隔延时、发送条数限制，并在界面上实时显示发送和接收的数据，以及发送统计信息。

## 主要功能

- **Excel 文件读取**：支持 `.xlsx` 和 `.xls` 格式，自动识别工作表的已使用区域，读取命令和预期返回值并显示在表格中。
- **TCP 网络通信**：通过 TCP Socket 连接到指定的 IP 地址和端口，发送 SCPI 命令并接收设备返回的数据。
- **多线程发送**：命令发送逻辑运行在独立线程中，避免阻塞 GUI，支持开始/停止发送。
- **发送控制**：
  - 可设置每条命令之间的延时（毫秒）。
  - 可设置总发送命令条数限制（0 表示无限循环）。
  - 支持手动停止发送。
- **实时显示**：
  - 发送的命令和接收的数据分别显示在两个列表中，自动限制最大显示条目（默认 300 条）。
  - 动态显示已发送的总命令条数。
- **线程安全停止**：发送线程采用原子标志位实现可中断的忙等待，确保快速响应停止请求。

## 编译与运行环境

- **开发框架**：Qt 5.x 或 Qt 6.x（使用 Qt Creator 或 qmake 构建）
- **编译器**：支持 C++11 的编译器（MSVC、MinGW、GCC 等）
- **依赖模块**：
  - `core`、`gui`、`widgets`
  - `network`（用于 TCP Socket）
  - `axcontainer`（用于操作 Excel，需 Windows 平台且安装 Excel 或 WPS）
- **操作系统**：Windows（因为使用了 `QAxObject` 访问 Excel）

## 构建步骤

1. 使用 Qt Creator 打开项目文件 `ExcelSCPISender.pro`。
2. 配置构建套件（确保已安装 `axcontainer` 模块）。
3. 编译运行。

或者使用命令行：

```bash
qmake ExcelSCPISender.pro
make   # 或 mingw32-make / nmake
```

## 使用说明

### 1. 连接电源设备

在界面中输入电源的 **IP 地址** 和 **端口号**（默认示例：127.0.0.1:20108）。

点击 **“连接到电源”** 按钮建立 TCP 连接。连接成功后，按钮状态会切换。

### 2. 加载 Excel 命令文件

点击 **“打开 excel 并读取”** 按钮，选择包含命令的 Excel 文件。

文件必须至少包含两列：

- **A 列**：需要发送的 SCPI 命令（字符串）
- **B 列**：期望的正确返回值（可选，当前版本仅用于显示，未做自动校验）

读取成功后，表格中会显示所有命令及对应的返回值。

### 3. 配置发送参数

- **每条命令发送延时(ms)**：相邻两条命令之间的等待时间（毫秒）。
- **发送条数(0为一直循环)**：总共发送的命令条数（如设置 100，则发送完 100 条后自动停止）；设为 0 表示无限循环，直到手动停止。

### 4. 开始发送

点击 **“发送excel命令到电源”** 按钮，程序将按顺序逐条发送 A 列的命令。

发送过程中，界面上的“总计发送命令”计数器会实时更新。

发送的命令会显示在右侧“发送的数据”列表中，接收到的设备响应显示在中间“接受的数据”列表中。

### 5. 停止发送

点击 **“停止发送excel命令到电源”** 按钮，发送线程会在当前命令发送完成后尽快停止。

发送结束后，按钮状态恢复，可以重新修改参数并再次发送。

### 6. 断开连接

点击 **“断开链接”** 按钮关闭 TCP 连接，并释放相关资源。

## 关键设计说明

### 多线程架构

- **GUI 线程**：负责界面事件、用户操作响应。
- **网络线程**：运行 `connectNetwork` 对象，处理 TCP 连接、读写，避免网络 I/O 阻塞界面。
- **发送线程**：运行 `ExcelSendWorker` 对象，控制发送节奏（延时、循环、停止标志）。  
  使用 `std::atomic<bool>` 作为停止标志，并通过 `QThread::yieldCurrentThread()` 实现微秒级可中断延时。

### 信号与槽连接

- 发送线程通过 `sendCommand` 信号将命令传递给网络线程（队列连接，自动跨线程）。
- 停止信号使用 **`Qt::DirectConnection`**，确保在 GUI 线程直接调用 `stopWork()`，立即设置原子标志，避免因发送线程阻塞导致无法响应。

### Excel 读取兼容性

- 尝试读取单元格的 `Value`、`Text`、`Value2` 属性，以兼容不同版本的 Excel 内容格式。
- 使用 `UsedRange` 获取实际数据区域行数，避免读取空行。

## 注意事项

1. **Windows 平台 + Excel/WPS**：由于使用了 `QAxObject`，本软件仅能在 Windows 上运行，且需要安装 Microsoft Excel 或 WPS（支持 COM 自动化）。
2. **线程安全**：网络对象的 `deleteLater()` 和线程退出等待处理正确，避免资源泄漏。
3. **界面响应**：发送过程中界面不会卡死，但停止信号最多会在当前命令发送完成后生效（即延时期间可立即停止）。
4. **显示限制**：发送和接收列表默认最多显示 300 条，超出会自动删除最旧条目，避免内存占用过大。
